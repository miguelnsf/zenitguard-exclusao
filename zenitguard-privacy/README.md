# ZenitGuard — Política de Privacidade (site público)

Site **separado** do repositório privado do app. Contém apenas esta página HTML.

## Publicar no GitHub Pages

### 1. Criar repositório novo (público)

1. [github.com/new](https://github.com/new)
2. Nome sugerido: **`zenitguard-privacy`**
3. **Public** (obrigatório para Pages grátis)
4. **Não** adicionar README (já existe aqui)
5. Criar

### 2. Enviar estes arquivos

No terminal, nesta pasta (`Documentos/zenitguard-privacy`):

```bash
git init
git add index.html README.md
git commit -m "Política de privacidade ZenitGuard"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/zenitguard-privacy.git
git push -u origin main
```

Troca `SEU_USUARIO` por `miguelnsf` (ou o teu user).

### 3. Ativar GitHub Pages

1. Repo → **Settings** → **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main** → pasta **/ (root)** → **Save**
4. Espera 1–3 min

### 4. URL para a Play Console

```
https://miguelnsf.github.io/zenitguard-privacy/
```

(Substitui o usuário se for diferente.)

Testa no telemóvel em modo anónimo — tem de abrir sem login.

## Atualizar depois

Edita `index.html` → commit → push. A URL não muda.
